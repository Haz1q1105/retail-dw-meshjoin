Cleaning (done by Mesh-Join/dataprep.py)
  Kept a transaction only when quantity > 0, unit price > 0, customer ID present,
  and the invoice number does not start with C (cancellation).
  Before: 541,909 transactions
  After:  397,884 transactions

Rules
  stable(text, n) = MD5 of the text (UTF-8), first 8 hex characters as an integer, modulo n
  sales_mode: stable(transaction_id, 10) is 0-6 -> Online, 7-9 -> Periodic
  store_id:   Online -> 1, Periodic -> 2 + stable(transaction_id, 4)
  Customer:   gender stable(id, 2); age group stable(id + "age", 7); occupation stable(id + "occ", 10);
              city category stable(id + country, 3); stay years stable(id + "stay", 5);
              marital status stable(id + "mar", 2)
  Product:    name = longest Description (UNKNOWN if empty); category stable(id + "cat", 10);
              supplier stable(id, 5)
